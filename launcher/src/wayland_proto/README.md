# wayland_proto — vendored pywayland protocol classes

Generated Python bindings for the Wayland core protocol and
`wlr-foreign-toplevel-management-unstable-v1`, committed into the repo so the
switcher backend (`toplevel_manager.py`) works out of the box on devices.

Upstream pywayland ships no `wlr_foreign_toplevel_management_unstable_v1`
module, so without this vendored package every device degrades to a disabled
toplevel manager unless someone hand-runs the scanner after install.

## Provenance

- Generated by: **pywayland 0.4.19** scanner (`python -m pywayland.scanner`)
- Source XMLs: the copies vendored in this repo at `launcher/data/`:
  - `wayland.xml`
  - `wlr-foreign-toplevel-management-unstable-v1.xml`
- Files: `wayland.py`, `wlr_foreign_toplevel_management_unstable_v1.py`

## Regenerating

From the repo root with the project venv active:

```sh
sed 's/ interface="wl_object"//g' launcher/data/wayland.xml > /tmp/wayland.xml
python -m pywayland.scanner -o launcher/src/wayland_proto \
    -i /tmp/wayland.xml launcher/data/wlr-foreign-toplevel-management-unstable-v1.xml
```

Both `-i` inputs must be under a **single** `-i` flag (the scanner's
`nargs="+"` option replaces its list when the flag repeats), and the wlr XML
must be scanned together with wayland.xml because it references `wl_seat` and
`wl_output`.

The `sed` step drops the stale `interface="wl_object"` attribute carried by
the vendored (older-revision) `wayland.xml`. pywayland's scanner requires
every referenced interface to be declared in one of its input files, and
`wl_object` is not a declared interface; current upstream wayland.xml removed
the attribute and upstream's own generated module types that argument as
plain `object`. The attribute only affects a type annotation on
`wl_display.error`; wire format and runtime behavior are unchanged.

## Do not edit

The `.py` files in this directory are generated. Edit the XMLs in
`launcher/data/` and regenerate instead; every generated file carries a
provenance header stating the generator version and command.
